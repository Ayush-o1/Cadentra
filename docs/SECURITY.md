# Security

What was considered, what controls exist and where they are tested, and what is not done. Sources are the OWASP Top Ten and the OWASP Password Storage and Session Management guidance; the Phase 0 research notes which of those figures were seen only in secondary summaries ([RESEARCH.md](RESEARCH.md)). This is a self-review, not an external audit.

## Threats and controls

| Risk                                     | Control                                                                                                                                                                                                                                                                                                | Tested in                                                                                                            |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **Broken access control, IDOR**          | The workspace comes from the session, never the request. Every query is scoped by it. Foreign IDs return 404. Composite foreign keys make cross-tenant links impossible at the database                                                                                                                | `contacts`, `campaigns`, `analytics`, `database` integration tests (each resource is probed from a second workspace) |
| **Credential attacks**                   | Argon2id (19 MiB, 2 passes, 1 lane). Identical response and comparable work for unknown account and wrong password. Rate limits per IP and per account; the account key is the lower-cased email so many IPs cannot share a budget                                                                     | `auth`                                                                                                               |
| **Session theft or fixation**            | 256-bit random token, only its SHA-256 hash stored. `HttpOnly`, `SameSite=Lax`, `Secure` and the `__Host-` prefix over https. New token on every login. Idle (7 d) and absolute (30 d) expiry. Revocable. Password change revokes the others                                                           | `auth`                                                                                                               |
| **CSRF**                                 | `SameSite=Lax`, plus an `Origin`/`Sec-Fetch-Site` check on writes, plus JSON-or-CSV-only bodies, which an HTML form cannot send                                                                                                                                                                        | `auth` (cross-site section)                                                                                          |
| **SQL injection**                        | Prisma parameterises. The few raw queries use tagged templates with bound parameters; dynamic filters are built from `Prisma.sql` fragments. LIKE wildcards in search terms are escaped                                                                                                                | `contacts` (wildcard test)                                                                                           |
| **XSS**                                  | The frontend builds DOM with a helper that only inserts text nodes. Strict CSP: `script-src 'self'`, no inline scripts or styles, `frame-ancestors 'none'`. Outgoing HTML email escapes all contact data                                                                                               | `app`, `compose`, e2e                                                                                                |
| **Header injection in email**            | Subjects are collapsed to one line; the sender display name is stripped of quotes and newlines; merge values never reach header fields except the subject                                                                                                                                              | `compose`                                                                                                            |
| **Template injection**                   | Merge fields are a fixed allow-list substituted as plain text. Values are not re-scanned (`{{company}}` inside a name stays literal). Unknown fields are rejected at save time                                                                                                                         | `template`                                                                                                           |
| **Forged or replayed webhooks**          | Svix HMAC signature over the raw body, with timestamp tolerance (5 minutes). Events deduplicated by id                                                                                                                                                                                                 | `webhooks`                                                                                                           |
| **Forged unsubscribe links**             | `messageId.HMAC(APP_SECRET)`. Constant-time comparison. Malformed, tampered and unknown tokens are 404 and cause no change                                                                                                                                                                             | `unsubscribe-token`, `unsubscribe`                                                                                   |
| **Abuse as a spam tool**                 | A consent basis is required for every contact and import, with a confirmation. Launch is blocked without sender identity and postal address. Daily send cap. Suppression re-checked at send time. Auto-pause when bounce or complaint rates approach the provider's limits. Unsubscribe in every email | `contacts`, `campaigns`, `worker`, `webhooks`                                                                        |
| **Open redirect on login**               | `next` is accepted only if it is a single-slash internal path                                                                                                                                                                                                                                          | frontend code review                                                                                                 |
| **CSV abuse and formula injection**      | 5 MB and 5,000-row caps, text body only, per-row validation. Downloaded problem reports prefix cells starting with `= + - @`                                                                                                                                                                           | `contacts`, `frontend`                                                                                               |
| **Information exposure**                 | Errors outside `AppError` become a generic 500 with the detail logged only. No stack traces. `X-Powered-By` removed. API responses `no-store`. Secrets redacted in logs                                                                                                                                | `app`, smoke test                                                                                                    |
| **Clickjacking, sniffing, cross-origin** | Helmet: CSP `frame-ancestors 'none'`, `nosniff`, `Referrer-Policy: no-referrer`, COOP/CORP same-origin, HSTS in production. Permissions-Policy denies camera, microphone, geolocation, payment                                                                                                         | `app`, smoke test                                                                                                    |
| **Denial of service**                    | Body limits (100 kB JSON, 5 MB CSV, 1 MB webhook), API rate limit (600/min/IP), pagination caps, bounded import size, Argon2 password length cap (128)                                                                                                                                                 | partial: `auth` (throttle)                                                                                           |
| **Secrets**                              | Environment variables only, validated at startup (including minimum lengths), never committed. `.env` is git-ignored; examples contain no values                                                                                                                                                       | secret scan, below                                                                                                   |
| **Vulnerable dependencies**              | Few runtime dependencies. `npm audit` runs in CI and was clean at the time of writing                                                                                                                                                                                                                  | CI                                                                                                                   |

## Auditing

Important actions write to `activity_log` (workspace created and updated, contacts created, edited, deleted and imported, lists, campaign lifecycle, suppressions, unsubscribes). The dashboard shows the latest entries.

## Verification performed for this release

- Automated accessibility scan (axe, WCAG 2.1 A and AA) on every page and the contact dialog, which found and fixed two real problems.
- `npm audit` for runtime and development dependencies: results are in the completion report and CI logs.
- Secret scan of the working tree and history: results are in the completion report.
- Headers checked against the production container with the smoke test (`scripts/smoke-test.mjs`).

## Known gaps

These are real and are not hidden by the controls above.

- **No email verification at sign-up.** Anyone can register with any address. Sending still requires a sender identity on a domain verified with the provider, a consent basis per contact, and the daily limit, but account abuse is not prevented.
- **No password reset, no multi-factor authentication, no account lockout beyond rate limiting.**
- **Rate limits are in memory.** They reset on restart and are per instance. Behind a proxy `TRUST_PROXY=true` must be set so the client IP is correct.
- **Single owner per workspace.** There are no invitations; the `member` role exists in the schema and is enforced where it matters (workspace settings) but cannot yet be assigned through the UI.
- **No per-workspace provider keys.** One provider key lives in the server environment.
- **Erasure is incomplete for audit data.** Deleting a contact removes its recipient and message rows, but the activity log keeps the event type (not the address, except unsubscribes and suppressions, which record the address by design).
- **Self-audited.** No penetration test or external review has been done.
